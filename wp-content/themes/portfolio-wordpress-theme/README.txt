PORTFOLIO — MODERN & ELEGANT WORDPRESS THEME

INSTALLATION
1. Extract this ZIP.
2. Copy the folder "portfolio-wordpress-theme" into:
   C:\laragon\www\YOUR-SITE\wp-content\themes\
3. In WordPress Admin, open Appearance > Themes.
4. Activate "Portfolio — Modern & Elegant".
5. Go to Settings > Permalinks and click Save Changes.

CREATE THESE PAGES
- Home (WordPress Settings > Reading: set as homepage if needed)
- About (slug: about)
- Projects (slug: projects)
- Contact (slug: contact)
- Member 01 (slug: member-1)
- Member 02 (slug: member-2)
- Member 03 (slug: member-3)
- Member 04 (slug: member-4)

For each Member page, select the "Member Profile" template in the Page editor.
The member profile content is currently placeholder content. Edit member names, roles,
bios and skills in functions.php inside portfolio_elegant_member_data().

CUSTOMIZATION
- Main styles: assets/css/theme.css
- Animations: assets/js/theme.js
- Homepage: front-page.php
- Member profile layout: page-member.php
- Header/navigation: header.php
- Footer: footer.php

This theme loads Bootstrap 5.3.3 and Google Fonts from their CDNs, so an internet
connection is needed for those external assets. Replace placeholder names, text,
projects, and contact information before publishing.
